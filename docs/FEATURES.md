# PlanFlow · 完整功能清单

> 版本 0.1.0 · 最后更新 2025-07

---

## 一、队列管理

| # | 功能 | 说明 |
|---|---|---|
| Q-01 | 文件导入 | 支持拖拽或点击上传 `.md`、`.markdown`、`.txt` 文件 |
| Q-02 | 多文件并行 | 每个文件对应一个独立队列，互不干扰 |
| Q-03 | 同名文件更新 | 再次导入同名文件时更新队列，尽量保留原有完成状态 |
| Q-04 | 队列搜索 | 左侧面板实时搜索队列名称 |
| Q-05 | 队列重命名 | 双击或通过编辑按钮修改队列名称 |
| Q-06 | 队列类型 | 5 种类型：学习 / 工作 / 生活 / 运动 / 其他，各有专属配色 |
| Q-07 | 队列类型推断 | 导入时根据文件标题关键词自动推断队列类型 |
| Q-08 | 队列删除 | 带二次确认的删除操作，防止误删 |
| Q-09 | 数据持久化 | 所有队列保存在 `localStorage`（key: `planflow.file-queues.v2`） |
| Q-10 | 进度导出 | 将当前完成进度导出为新的 Markdown 文件（`.md` 下载） |

---

## 二、任务操作

| # | 功能 | 说明 |
|---|---|---|
| T-01 | 任务完成/恢复 | 点击勾选框切换完成状态，已完成任务显示删除线 |
| T-02 | 任务筛选 | 全部 / 待办 / 已完成 三档快速筛选 |
| T-03 | 任务搜索 | 在当前队列内实时搜索任务标题 |
| T-04 | 任务新增 | 快速输入框新增任务，支持设置标题、时间、备注、子内容 |
| T-05 | 任务编辑 | 编辑已有任务的标题、时间、备注、子内容 |
| T-06 | 任务删除 | 带二次确认的删除操作 |
| T-07 | 任务展开 | 点击任务行展开"这一小时要做什么 / 具体内容 / 来源段落" |
| T-08 | 任务折叠 | 再次点击或点"收起"折叠任务详情 |
| T-09 | 状态反馈 | 导入、保存、删除、完成等操作均有 Toast 提示 |
| T-10 | 任务上限保护 | 单文件最多识别 120 项任务，超出时截断并提示 |

## 三、Markdown 解析引擎

| # | 功能 | 说明 |
|---|---|---|
| P-01 | 勾选项识别 | `- [ ]` 待办、`- [x]` 已完成 |
| P-02 | 普通列表 | 无序列表（`-`、`*`）和有序列表（`1.`）均识别为任务 |
| P-03 | 段落过滤 | 普通说明段落不会被误识别为任务 |
| P-04 | 时间段标题 | `## 学习 · 08:00-10:00` 格式，时间自动归一化 |
| P-05 | 多种时间格式 | `08:00`、`08:00-09:30`、`08:00 至 09:30`、`8点`、`上午8点` 等 |
| P-06 | H001 小时课程 | `## H001`、`## H002：基础类型`、`## H003 - 接口与泛型` 等格式 |
| P-07 | 小时范围文件名 | 文件名含 `H001–H024` 时自动识别课程范围 |
| P-08 | 子内容识别 | 缩进子列表、`说明：`、`内容：`、`重点：` 成为任务的具体内容 |
| P-09 | 表格解析 | Markdown 表格中的时间 + 任务行 |
| P-10 | 任务去重 | 相同时间 + 标题的任务自动去重 |
| P-11 | 原文保留 | 导入时保存完整原始 Markdown 全文（`rawContent`），供阅读器使用 |

## 四、全屏 Markdown 阅读器

| # | 功能 | 说明 |
|---|---|---|
| R-01 | 全屏覆盖 | 点击「预览原文」打开沉浸式全屏阅读器 |
| R-02 | 富文本渲染 | 使用 `marked` 将 Markdown 渲染为 HTML，支持标题、列表、加粗、链接、代码块等 |
| R-03 | XSS 防护 | `DOMPurify` 清洗渲染结果，禁用 `script`、`style`、`iframe` 等危险标签 |
| R-04 | 护眼主题 · 纸白 | 默认白底黑字，适合日间阅读 |
| R-05 | 护眼主题 · 护眼绿 | 低饱和绿底，减少蓝光刺激 |
| R-06 | 护眼主题 · 羊皮纸 | 暖黄底色，模拟纸质阅读感 |
| R-07 | 护眼主题 · 夜间 | 深色背景，适合低光环境 |
| R-08 | 字号调节 | A- / A+ 按钮调节正文字号（14px–22px） |
| R-09 | 进度记忆 | 每个队列独立记录滚动百分比，重新打开自动回到上次位置 |
| R-10 | 偏好持久化 | 主题和字号偏好保存到 `localStorage` |
| R-11 | Esc 关闭 | 键盘 Esc 键快速关闭阅读器 |
| R-12 | 空内容提示 | 手动创建的队列无原始内容时显示友好提示 |

## 七、工程化

| # | 功能 | 说明 |
|---|---|---|
| G-01 | TypeScript 全覆盖 | 所有源文件使用 TypeScript，`vue-tsc` 类型检查通过 |
| G-02 | 单元测试 30 项 | Vitest 驱动，覆盖解析引擎、时间工具、渲染工具、构建配置 |
| G-03 | 双测试环境 | 纯函数用 `node` 环境，DOM 相关（renderMarkdown）用 `jsdom` 环境 |
| G-04 | 生产分包 | Vue 框架独立打包为 `vendor-vue`，业务代码与框架分离，利于长效缓存 |
| G-05 | 内容哈希 | 产物文件名含内容哈希，配合 CDN 实现强缓存自动破缓存 |
| G-06 | 生产关闭 sourcemap | 生产构建不输出 `.map` 文件，防止源码泄漏 |
| G-07 | Tailwind safelist | 动态拼接的类型配色类显式加入 safelist，防止生产 purge 掉色 |
| G-08 | 设计令牌 | 品牌色通过 Tailwind 主题暴露为语义色（`sage`、`orange`、`ink` 等） |
